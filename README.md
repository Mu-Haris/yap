## Before going live

1. Edit `app-ads.txt` and replace `pub-0000000000000000` with your real AdMob publisher ID.
2. Once your app is approved on the App Store, update the App Store URL inside `index.html` (search for `apps.apple.com/app/yap` and replace with the real URL — the QR code will regenerate automatically).
3. In AdMob console, set your developer website to `https://mu-haris.github.io/yap/` so the `app-ads.txt` crawl can find it.
